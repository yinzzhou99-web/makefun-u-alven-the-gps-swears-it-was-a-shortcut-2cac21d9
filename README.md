**The GPS Swears It Was a Shortcut** — the GPS's excuse in its own voice: deadpan, blaming an outdated map while the lake quietly takes the blame for existing.

## Entry

`main.py` (stdlib only) writes the excuse to `/output/entry.txt`:

> In my defense, that road was on the 2019 map. The lake moved in later.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
